## Adicionar uma documentação

1. Criar pasta com o nome do projeto e colocar o `index.html` dentro.
2. Adicionar um card em `index.html` (raiz) e uma linha na tabela acima.
3. Commit e push na `main` — o Pages publica sozinho.

Este repositório é público: nunca colocar chave, senha, IP interno ou dado real de cliente.
